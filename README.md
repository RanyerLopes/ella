# Ella Beauty - Landing Page

Landing page premium para **Ella Beauty**, estúdio de estética em Porto Velho, RO.

![Ella Beauty](assets/logo.png)

## Sobre o Projeto

Site institucional desenvolvido para divulgação dos serviços de estética e captação de clientes via WhatsApp. Otimizado para tráfego vindo do Instagram.

## Tecnologias

- **HTML5** - Estrutura semântica
- **CSS3** - Estilização com variáveis CSS e responsividade
- **JavaScript** - Interatividade e animações
- **Font Awesome** - Ícones
- **Google Fonts** - Tipografia (Cormorant Garamond + Montserrat)
- **Google Maps** - Mapa integrado

## Funcionalidades

- Design responsivo (mobile-first)
- Botão flutuante do WhatsApp
- Formulário de contato integrado com WhatsApp
- Menu mobile com animação
- Animações suaves ao scroll
- Mapa de localização integrado
- SEO otimizado
